Reference

Deep reference

A page per module, written for people changing the code. Dense, precise, and assumes you know the vocabulary.

Read this first. These pages are an engineering record, not a user guide. They record why a mechanism is shaped the way it is — including the bugs that shaped it — which makes them invaluable when you're modifying something and impenetrable when you're trying to learn the system. If you're new, use the guide pages in the sidebar; come back here when you need to change code.

Keep the glossary open beside them.

What this reference doesn't cover

Being straight about the gaps, so you don't go looking for a page that isn't here. As of 2026-08-04 these parts of src/ghost_agent/ have no page in this section — though Checking and learning explains what the background passes do:

PackageWhat's in it
selfhood/The implementation behind the selfhood algorithm page — autobiographical store, narrative, recognition, values.
workspace/Likewise for workspace continuity — activity ledger, reactions, state.
distill/Trajectory collection, redaction, outcome heuristics, user-correction promotion.
optim/The prompt loader, signatures and gate contract that render tool descriptions. (The optimizer, its autonomy loop and the A/B evaluator were removed on 2026-10-11, §4NM.)
eval/The evaluation suite and baselines. (The bench banks were removed on 2026-10-11, §4NM.)
utils/Logging, redaction, the egress guard, tokenisation, constraint handling.
~20 core/ modulesIncluding metacog, turns, subagent, jobs, failure_replay, learning_health, stream_guards.

The learning stack that used to sit beside these packages — reflection/, skills_auto/, prm/, router/, evolve/, the optimizer half of optim/ — was removed on 2026-10-11 (§4NM); The learning loop describes what replaced it.

Two pages describe modules that no longer exist: core/workspace_model (the code now lives in workspace/model.py) and tools/qwen_bridge (removed). core/agent_qwen is an intentional tombstone. They're kept so existing links don't break — treat their contents as historical.
