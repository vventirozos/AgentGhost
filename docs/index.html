Ghost Agent

A personal AI agent that runs on four machines at home. It talks and listens, searches the web and the dark web over Tor, draws pictures, remembers you, writes and runs code in a sandbox, spins up its own lab machines — and has a mood and a picture of itself.

Runs at home Tor-only egress No accounts, no API keys Docker sandbox Local models

Most AI assistants are a website you send text to. Ghost is a program you run. Nothing leaves the house unless you ask for something that needs the internet — and then it goes out through Tor.

One message, end to end

  1. You send a message

    From the web console, Slack, the handheld, your voice or a plain HTTP request. It all arrives at the same place.

  2. Ghost puts what it knows in front of the model

    Your profile, the facts it holds about you, the rules you gave it, and — for its own voice — its current mood.

  3. The model answers or reaches for a tool

    Search, browse, run code, read a file, draw a picture, open a lab. Anything that touches a machine runs in a container; anything that touches the internet goes through Tor.

  4. It repeats until the job is done

    Each tool result goes back to the model, which picks the next step.

  5. Program checks look at what it delivered

    Does the page it built load, are the files it claims on disk, does the picture show what it says? A failure gets one repair round before the reply goes out.

The long version: One message, end to end.

Is this for you?

A good fit if

  • You want your conversations to stay on your own disks.
  • You want an assistant that remembers your projects for weeks, not one chat.
  • You are comfortable running a few services and reading a log.

A poor fit if

  • You want zero setup: it needs Docker, Tor and a local model server before it starts.
  • You need frontier-model quality. A local model trades raw capability for privacy and control.

What it costs

A local model reasons less well than a frontier API. Search over Tor against scrapers is slower and less accurate than a keyed search API. The checks are mechanical: they catch a broken page or a missing file, not an invented fact — on hand-graded turns about 43% of answers were right and 14% wrong, and invented knowledge is the main open failure. More moving parts means more that can quietly stop, which is why so much of the tooling exists to notice that.
