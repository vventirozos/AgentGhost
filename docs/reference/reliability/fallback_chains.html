tools / fallback_chains.py

Suggest alternative tools when a tool fails so the agent doesn't waste a turn.

Chains

Failed toolFallback chain
deep_researchweb_search → recall
web_searchdeep_research → recall
executefile_system

API

  • get_fallback_chain_hint(failed_tool, error_text="") -> Optional[str] — Returns "FALLBACK SUGGESTION: …" for the first usable fallback in the chain. It skips web_search on a CAPTCHA error and execute on a docker error. The turn loop imports it as get_fallback_hint; do not confuse it with tool_failure.get_fallback_hint.

No chain for vision_analysis 2026-10-04 §4LM

The vision_analysis → file_system suggestion ("read the file as text") was removed. It led to a binary-file refusal that points back at vision. It contradicted the failure's own "Do NOT retry". It also named a tool members cannot use. Each vision failure message now carries its own next step.
