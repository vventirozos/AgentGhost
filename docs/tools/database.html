database (removed)

2026-11-04 §4SX E The postgres_admin tool (tools/database.py) and the Mac's local PostgreSQL are gone.

  • What replaced it. SQL runs on a real database on a disposable lab machine: lab create (for example the pg-single or mysql-single template), then lab exec. See labs and runs. Plain data work runs in execute (sqlite3, pandas).
  • What went with it.
    • the --default-db / GHOST_DEFAULT_DB setting;
    • the SQL pre-execution validator (validate_sql, only validate_shell is left in tools/validators.py);
    • its fallback chain and failure hints;
    • the behavioural eval's database case;
    • the default_db capability clear in replay isolation.
  • A model that still calls it (postgres, postgres_admin, postgres-admin, postgresadmin) is mapped to lab. lab's answer lists its own actions.
  • The old page is kept in the backups (~/Data/AI/Data/backups/4sx-e-removed/).
