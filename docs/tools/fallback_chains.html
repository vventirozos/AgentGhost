No chain for vision_analysis 2026-10-04 §4LM

The vision_analysis → file_system suggestion ("read the file as text") was removed. It led to a binary-file refusal that points back at vision. It contradicted the failure's own "Do NOT retry". It also named a tool members cannot use. Each vision failure message now carries its own next step.
