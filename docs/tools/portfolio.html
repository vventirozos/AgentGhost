tools / portfolio.py

The portfolio tool: the owner's IBKR holdings, read from a separate service. 2026-11-06

Why it is a separate service

The agent stays on Tor and holds no keys for outside accounts. A brokerage connection is tied to the owner by nature, so it lives in interface/ibkr-service, on another machine, on the normal internet, by the operator's choice. The agent only reads text from it over the tailnet. See the service's README.md for setup and operation.

Configuration and visibility

  • GHOST_PORTFOLIO_URL: the service's address, such as http://100.64.0.2:8095. Unset means the tool isn't advertised.
  • GHOST_PORTFOLIO_KEY_FILE, default ~/Data/AI/.ibkr_service_key, mode 0600. An empty file also hides the tool. The key is redacted from stored text by value.
  • Members never get it: it's outside _MEMBER_ALLOWED_TOOLS, and the tool refuses a member by itself as well. Contained contexts have it in their forbidden set.

Actions

actionArgumentsWhat it returns
summary—Value, cash, total, gain against cost, today's change, dividends, and one line per holding.
positionsymbolOne holding with its average cost and recent trades.
health—Concentration, currency mix, and how today's mix would have behaved: volatility, worst fall, correlation, comparison with the benchmark.
forecastsymbol (optional)The range of past returns over 1 month, 3 months and 1 year. A horizon needs twice its length in history, or it's left out.
review—Prompts from fixed rules, each with its reason and the case against acting. Never a buy or sell instruction.
status—Whether the token and query are present, and when data last arrived. No holdings.

Results

Every figure is computed by the service, and the tool passes its text through unchanged. A failure starts with Error:, so the turn loop sees it through result_is_failure. Old or missing data is labelled inside a successful result, as STALE or Data gap, because the figures that remain are still usable.

What it can't do

It can't trade. The service has no order code and accepts only GET, and Flex only hands out reports. The agent never sees the Flex token or the account id, which the service never stores.
