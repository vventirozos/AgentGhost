tools / tool_failure.py

Failure classification taxonomy. Decides whether a failed tool should retry, replan, or self-correct.

Classes

ClassPatterns (regex)Agent action
RETRYABLEtimeout · rate-limit · connection reset · 502/503/504Retry with exponential backoff up to MAX_RETRIES = 3.

Classify the error, not the advice 2026-09-15

Tools append a --- HINT --- block to a failure for the model's benefit, and those hints enumerate failure modes by name — the browser's begins "If this is a navigation timeout, try wait_until='domcontentloaded'…". Patterns are scanned in order with first match winning, so the hint decided the class of the error it was attached to. Live: a deterministic 

ValueError: selector '.frag_copy' did not match any element

was booked RETRYABLE on the word "timeout" three paragraphs below it, and charged to the transient strike budget (Transient strike 1/4 (timeout)) — a budget no retry can satisfy, because the selector will never match. Measured across the recorded trajectory corpus, 31 of 53 hinted tool errors (58.5%) changed class once the advice was excluded, every one of them retryable → diagnostic/unknown.

strip_advisory_sections now removes advisory blocks before classification — a dashed rule, a short label ending in HINT, a dashed rule — matched generically so execute's --- 💡 DIAGNOSTIC HINT --- (different label, different rule length) is covered by the same implementation. It cuts to the block's closing rule rather than to end-of-text, so anything appended after a hint survives; text with no hint is returned unchanged; and a result that is nothing but advice classifies UNKNOWN rather than inventing a failure. tests/test_tool_failure_hint_stripping.py carries an ast.parse enumeration that walks every string constant in src/ and fails if a producer ever invents a banner shape the stripper cannot see.

Per-tool hints

_FALLBACK_HINTS attaches a tool-specific suggestion when a known signature fires:

  • execute + ModuleNotFoundError → "pip install X first".
  • file_system + "not found" → "run list_files first".
  • web_search + CAPTCHA → "DuckDuckGo rate-limiting; shorter query".
  • postgres_admin + timeout → "add LIMIT or push filters into WHERE".
