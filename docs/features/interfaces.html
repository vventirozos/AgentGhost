Feature

Interfaces

The agent itself is an HTTP service with no screen of its own. A web console, a Slack bot, a handheld, a command line and an API all talk to it, and they all share one memory.

Runs on: Mac Studio (eva) Clients: browser, Slack, ClockworkPi, terminal

What it does

Ghost has one brain and many doors. Memory, projects and your rules belong to the agent, not to the window you type in. Start something in Slack on your phone, finish it in the web console at your desk, and Ghost knows it is the same work.

Each interface is a separate program. You can restart one without touching the others, and if a page loads but nothing answers, that tells you the agent is down, not the console.

InterfaceBest for
Web consoleDay-to-day use. The most complete one: streaming replies, files, voice, the live log, the animated face.
Slack botReaching Ghost from anywhere, and letting a few other people in a channel ask it things.
ClockworkPi handheldA small dedicated screen you can carry around.
CLIQuick questions from a terminal or a shell script.
HTTP APIBuilding something of your own. OpenAI- and Ollama-shaped endpoints.

How it works

The web console

A chat page with what a local agent needs: file upload (pick or photograph a file and ask about it in the same step), downloads of files Ghost made, memory correction, a project view, and saving or loading a whole workspace as a zip. Replies stream word by word. Every message has a ⋯ menu: Regenerate on a reply, Edit & resend on yours. A turn that stops early carries a Retry button.

Behind the chat sits the face: an animated corridor of frames around a glowing kernel that shows what Ghost is doing and how it feels. It runs hot while Ghost works, scans while it searches, draws inward while it reads, and finishes with a green ring when a turn went well or red when it went wrong. Each mood (cheerful, calm, curious, tired and so on) has its own colours and tempo. One button in the header turns the face and its animations off and on; the choice is saved on the server, so every device follows it.

Installed on a phone as a home-screen app, the console opens even offline, resumes a turn that was running when you closed it, and asks before enabling push alerts (on an iPhone, add it to the Home Screen first).

The Slack bot

The bot connects out to Slack, so nothing is exposed to the internet. Direct messages are answered for the owner only. In channels you add it to, it also answers other people in your workspace; set GHOST_SLACK_OPEN_CHANNEL=0 to lock it back to you alone. Slack sometimes delivers a message twice; the bot remembers each message for ten minutes and answers it once. If the bot is restarted mid-request, it posts a note in the thread asking you to send it again.

To silence someone, list their Slack member IDs in GHOST_SLACK_SHADOW_BAN. Their messages and reactions are dropped without a reply, and the owner can never be banned by mistake.

A channel member is not the owner

When Bruno, a colleague in a shared channel, asks Ghost something, his turn is walled off from Elena, the owner. The client tells the agent who is asking (owner or member). A member's turn gets plain web search (including dark-web search), image making and looking at pictures, nothing else: no files, no code, no browser, no memory. Elena's profile, address, location, recall and private data never appear in it, and tools that would read or change her data are refused. Ghost is told this up front, so Bruno gets a plain “that can't be done on this channel” rather than a hunt for a way around. A member's own pasted image is kept as his file, not Elena's.

A member never teaches

Nothing a member does changes how Ghost treats the owner. A member's turn writes nothing to the owner's memory or journal, is not used to grade or tune the agent, does not update its record of what tools work, and loads no owner recall into the conversation. Slack requests are tagged as such, so a rating on them is kept with that turn but never turns into a lesson.

Maintenance mode

While maintenance is on, the Slack bot sends nothing to the agent: mentions, DMs (the owner's too), uploads and 👍/👎 all stop at the bot, and each message gets one maintenance reply in its thread. Strangers and banned users still get silence, and notifications from the agent still reach the owner.

The switch is one file, ~/Data/AI/Logs/ghost-slack-maintenance (path set by GHOST_SLACK_MAINTENANCE_FILE). The bot checks it on every message, so it takes effect at once and survives restarts. The file's text is the reply; an empty file gives a default “down for maintenance” line.

echo "Upgrading the model, back at 20:00" > ~/Data/AI/Logs/ghost-slack-maintenance   # on
rm ~/Data/AI/Logs/ghost-slack-maintenance                                          # off

The owner can also DM the bot maintenance on, maintenance on: back at 20:00, maintenance off or maintenance status. The command must be the whole message, so “maintenance on my car is due” is still an ordinary request.

The handheld and the CLI

The ClockworkPi uConsole client is a small native app for a carry-around screen. It keeps a local chat log and shows the same face. The CLI (interface/externals/cli/ghost) answers one question with -p, or opens an interactive session when run without arguments.

The HTTP API

Every interface above is a client of this. The main routes:

EndpointWhat it is for
POST /api/chatSend a message, streaming or not (Ollama-shaped).
POST /v1/chat/completionsThe OpenAI-shaped equivalent for OpenAI-compatible tools.
GET /api/healthIs it alive and healthy?
POST /api/upload · GET /api/download/…Move files in and out of the sandbox.
POST /api/turn/cancelStop a running turn.
GET /api/notifications/pendingAnything the agent needs you for.

Every call needs the X-Ghost-Key header. A client that serves other people also sends X-Ghost-Requester: member for their turns; no header means the owner.

Where it runs

The agent, the API, the web console server and the Slack bot all run on the Mac Studio (eva), each supervised so it restarts if it dies. Browsers, phones, the handheld and Slack reach them over a private network. Voice requests are passed on to the Mac mini (nova) for speech-to-text and speech.

Limits and switches

  • Installing the console on a phone needs HTTPS with a certificate the phone trusts.
  • GHOST_SLACK_OPEN_CHANNEL=0 restricts Slack to the owner; GHOST_SLACK_SHADOW_BAN is read once at start, so a ban needs a bot restart.
  • A shared Slack channel is not a security boundary in itself: the member wall in the agent is what keeps the owner's data private.
  • Only the last notify_operator call of a request is sent.
  • A member's ratings are recorded but nothing acts on them.
