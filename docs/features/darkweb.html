Dark web search

Ordinary search engines do not index .onion sites. Ghost has its own path that asks the onion search engines (Ahmia, Torch, Torgle), lists the hidden services they find, and can read them for you.

Runs on: Mac Studio (eva) Tor-only

What it does

Two tools cover the hidden web:

  • darkweb_search returns a ranked list of onion services for a query, with titles and short descriptions.
  • darkweb_research goes a step further: it fetches the pages behind the best results and writes up what they say.

Everything found here is an unverified hidden service. Ghost is told to treat it as uncorroborated and to say so, rather than report it as fact.

Try it

You sayWhat happens
“Find the onion address of a well-known news site.”darkweb_search lists matching services and says which engines found each one.
“What do onion forums say about privacy-focused phones?”darkweb_research reads a handful of results and summarises them, labelled as unverified.
“Open that onion link.”The browser opens it over Tor inside the sandbox.

How it works

  1. Clean the query

    Google-style operators are removed, since the onion engines choke on them.

  2. Ask every engine

    The query goes to Ahmia (both its normal web address and its onion address), Torch and Torgle. Some engines need a hidden form token first, which Ghost fetches.

  3. Retry on a new route

    Whether an onion engine answers depends on which Tor exit you happen to use. Each retry forces Tor to build a fresh circuit instead of reusing the one that just failed.

  4. Count independent sources

    Ahmia's two addresses are two doors to the same index, so a result found by both counts as one source, not two. Only different indexes count as corroboration.

  5. Rank and report

    Results are merged, ranked, and returned with a clear “unverified” framing.

Where it runs

On the Mac Studio (eva), inside the agent, through the same Tor client as web search. Nothing goes out over the normal internet. Ahmia also filters known abuse material at its index, which is one reason it is listed first.

Limits and switches

  • Empty results are normal, not an error. They usually mean the engines were unreachable from the current exit. Repeating the same query word for word rarely helps; Ghost is told to try fewer keywords or fall back to ordinary search.
  • Onion sites appear and vanish often, and many pages are slow or dead.
  • Nothing returned is trustworthy by default. Treat names, prices and claims as leads, not facts.
  • The engine list is configuration, not code: set GHOST_ONION_ENGINES to a JSON list of {"name", "url", "index"} entries to change it.
  • Channel members in Slack may use darkweb_search (the list), but not darkweb_research.
